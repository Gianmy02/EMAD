# EMAD

Repository del corso **EMAD** dedicata allo sviluppo di progetti con **Flutter** e **Dart**.

## Obiettivo

Questo repository verrà usato per esercizi, esempi e progetti del corso.

## Branch di lavoro

Il lavoro verrà svolto **solo sul branch `main`**.

## Tecnologie

- Flutter
- Dart

## Requisiti consigliati

- Flutter SDK installato
- Dart SDK (incluso con Flutter)
- Un editor come VS Code o Android Studio con plugin Flutter/Dart
